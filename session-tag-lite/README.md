# `@local/session-tag-lite` — 会话标签（轻量，不接管侧栏）

给会话打标签的前端插件，形态参考 typeai WebUI 的「添加标签」：固定 `待办 / 存档` 语义、自由标签 + 全库标签池、截止日期，并在浮层面板里按标签浏览会话。

**左侧会话列表原样保留**——只占用宿主开放的座位（行尾按钮、`…` 菜单项、悬停卡片、浮层、顶部面板列表），不 shadow `sidebar.workspaces`；唯一例外是单列表里的**纯 CSS 槽位排序**（见下文「左栏标签排序」）。标签由 **Host 半区持久化**到 `~/.dsh/session-tag-lite/state.json`，浏览器 localStorage 只作即时渲染的缓存：换浏览器、清站点数据都不丢。

---

## 入口

| 位置 | 行为 |
| :--- | :--- |
| 会话行 hover → **色盘**按钮 | 打开「会话标签」弹窗；色盘是该会话标签颜色的合成（1 个=纯色圆，≥2 个=等分扇区，无标签=空心圆）。**可在「设置 → 通用设置 → 会话行尾标签按钮」关掉**（关掉后行尾不再占位，其余入口照常） |
| 会话行 `…` → **编辑标签** | 同一弹窗（排在 `fork` 之后、`archive` 之前），glyph 也是同款小色盘。菜单项写动词短语、不带省略号 |
| 会话行悬停卡片 | 标签 chip（点击打开标签面板并预填搜索）+ 截止日期徽章（过期变红）+「编辑标签」 |
| 左栏顶部面板列表 → **标签** 图标 | 打开标签总览面板 |
| 标签面板会话行 hover → **+** | 就地展开标签编辑条：标签池 chips 点一下即加/取消，输入框回车新建；不离开面板 |

> 刻意**不**在会话行行首（`sidebar.session.row.leading`）放色点：那个位置是宿主表达「未读 / 待回答 / 运行中」的状态点，再塞一个彩色圆点会被误读成状态。标签只出现在行尾色盘、悬停卡片、菜单与面板里。

弹窗里可以：新建标签（Enter，逗号分隔批量）、勾选/取消池中标签、删除本会话标签、设/清截止日期。改动即时保存，没有「保存/取消」两态。

## 通用设置行

「设置 → 通用设置」里有两行，都标 `模组`、都走 `settings.general.item`：

| 行 | `data-plugin-setting` | order | 控件 |
| :--- | :--- | :--- | :--- |
| **会话行尾标签按钮** | `session-tag-lite.row-action` | 15 | 开关 `options.rowAction` |
| **左栏标签排序** | `session-tag-lite.order` | 16 | 默认模式：存档置底开关 `options.archiveLast` + 「自定义排序…」；自定义模式：「编辑排序…」 |

两个开关都本地即时生效，并随整份状态推到 Host（`state.json`），换浏览器也保持。

- 关掉行尾开关只影响**行尾色盘**这一个座位：`…` 菜单的「编辑标签」、悬停卡片、`sidebar.panellist` 入口、标签总览面板全都不受影响。
- 「左栏标签排序」行只改视觉顺序；默认模式下开关关掉即恢复宿主块级顺序，不会移除任何标签数据。
- 只管本插件自己的座位。宿主的「归档 / 置顶 / ⋯ 菜单」不碰——按 `aria-label` 做 CSS 定向隐藏会在宿主改结构或文案时静默失效，不做。
- 视觉与宿主 / 其他模组的设置行同构（徽章 + 描述 + 36×20 开关，令牌取 `--dsw-alias-*`）。

## 标签总览面板

面板有**两种视图**，头部 `[树形 | 标签页]` 分段控件切换：

- **树形（默认）**：最近分区 + 标签组，组头可折叠（下面这张图）。
- **标签页**：把同一批分区变成顶部 tab，点击切换下方会话列表；tab 超过一行时**自动换行成多行**（VSCode wrap-tabs 行为），超过 150px 高才在 tab 栏内滚动。
- 视图选择存 `options.panelView`（localStorage + `state.json`），关闭面板、刷新、换浏览器都记住；旧数据/脏值缺省树形。**只记忆视图，不记忆当前 tab**，每次打开默认第一个（通常是「最近」）。
- 标签页的 tab 顺序与树形组一致（最近 → 待办 → 存档 → 自定义标签 → 未打标）；浏览态保留空的「待办 / 存档」tab 骨架，空 tab 显示「这个标签下还没有会话」。搜索时只保留有命中的 tab，当前 tab 被过滤掉时回落到第一个；支持 `←` / `→` / `Home` / `End` 键盘切换。

```
会话标签                        [树形 | 标签页]  [最近 24 ▾]  ×
[ 搜索标签或会话 ]                          ← 同时匹配标签名与会话标题

树形（默认）：
▾ 🕐 最近 24 小时    18   ← 时间维度（不是标签），含运行中会话；头部下拉改窗口
▾ ● 待办        2      ← 组头：底色条 + 字重 600 + 计数 pill
   ├ 面试问答      32分钟   ← 行尾相对时间（与左栏同款），hover 让位给 +
   └ 为 typeai 添加…  1小时
▸ ○ 存档        0      ← 保留组始终显示，空组也留骨架
▸ ● 读书        5
▸ ○ 未打标      225    ← 默认折叠；展开先露 15 条 +「显示全部 225 个」

标签页：
[🕐 最近 24 小时 18] [● 待办 2] [○ 存档 0] [● 读书 5] [○ 未打标 225]
[ 会话行（同一套行结构，无组头缩进）… ]
```

- 面板 760px 宽（`min(760px, 94vw)`）、最高 82vh；在 1244px 视口下约占 61%，比左栏宽但不算浮夸。
- 组头与会话行是**两级视觉**：组头 32px / 13px / 600 字重 / `bg-layer-2` 底；会话行 30px / 13px / secondary，hover 才升 primary。
- 会话行右侧**常显相对时间**：`刚刚 / N分钟 / N小时 / N天 / N个月 / N年`（与宿主左栏同一套分桶），鼠标移到行上时时间淡出、`+` 打标签按钮出现在同一位置——和左栏“hover 时时间让位给动作按钮”的手感一致。
- 子项缩进 13px + 1px 引导线（`--dsw-alias-border-l1`），和组头形成明确父子关系。
- `待办 / 存档` 在浏览态**始终存在**（哪怕 0 项），避免空组消失导致「看起来只剩两组」。
- `未打标` 默认折叠；点开后最多先显示最近 15 条，底部「显示全部 N 个」展开。搜索态下该组强制展开且显示全部命中。
- 搜索态只显示有命中的组，不出现一堆 0 计数。
- 点任一会话行 → 打开该会话并关闭面板。
- **归档筛选跟随左栏**：面板只显示左栏当前筛选口径内的会话（见下节「归档筛选联动」）。默认「隐藏已归档」下归档会话不上架；切到「全部对话（显示已归档）」会连带列出归档行（置灰 + `已归档` 标记），「仅显示已归档」则只列归档会话。

## 归档筛选联动（跟随左栏「视图选项」）

标签面板不自己发明可见口径：宿主左栏「视图选项 → 筛选会话」里选了哪一档，标签面板就显示哪一批会话。

| 左栏筛选 | 面板显示 | 面板头部 |
| :--- | :--- | :--- |
| 隐藏已归档（默认） | 只显示未归档会话（与旧版一致） | 无徽章 |
| 全部对话（显示已归档） | 未归档 + 归档一起显示 | `含已归档` |
| 仅显示已归档 | 只显示归档会话 | `仅已归档` |

- **归档行照样能打标签**：面板里仍可用 `+` 与标签池整理它们；行置灰、行内带 `已归档` 徽章，`title` 写明「打开时会先取消归档」。
- **点归档行 = 取消归档并打开**：宿主对归档会话的规则是「取消归档后才能打开」（否则主面板会被清成空白）。插件先调 `uiWorkspace.unarchiveSession`，成功后再走正常打开，两步都在面板内完成；服务缺失（老部署）时只提示，不做半截动作。
- **「仅显示已归档」下没有归档会话**：保留「待办 / 存档」骨架，空态文案提示「左栏切回隐藏已归档」，不假装是「还没打过标签」。
- **读取时机**：面板是模态浮层，打开期间点不到左栏，所以每次渲染读一次即可；切换筛选后重新打开面板就生效。
- 归档集仍来自 `ctx.workspaces.list.archivedSessionIds`；筛选模式只从宿主那一个状态键读，不猜、也不改宿主偏好。

> 插件自己的「存档」**语义标签**与宿主的**归档**仍是两回事：前者是你手动贴的整理维度，后者是宿主的会话收纳状态，两者互不写入。

## 「最近 N 小时」（时间维度，不是标签）

面板最上方有一个**非标签**的置顶分区：自动列出窗口内有过活动的会话（`updatedAt >= now - N 小时`），
**运行中的会话无条件纳入**（它的 `updatedAt` 可能滞后）。分区头用时钟图标而不是色点，它不进标签池、
不占「未打标」，也不参与孤儿清理。

- 默认 **24 小时**；面板头部「最近 24 ▾」下拉可切 `6 / 12 / 24 / 48 / 72 / 168` 小时，或输入自定义 `1–720`。
- 选择存在 `options.recentHours`（同一份 localStorage / `state.json`），换浏览器与重启都保留。
- **行序跟随左栏的槽位排序**（见下节）：自定义模式下按槽位先后、同槽内按最近活动倒序；默认模式只把「存档」置底，其余按时间。它不是标签，但横跨多个标签，所以和左栏用同一套顺序。
- **它自己也可以作为槽位被搬位置**：在排序设置里把「最近 24 小时」上下移，它既决定这个分区在面板里的位置，也决定最近窗口内的会话在左栏聚到哪一档（窗口可在面板头部调整）。
- 窗口内一个会话都没有时，该分区整体不出现（不会留一个空的「最近」）。
- 与标签正交：同一会话既在「最近」又在「待办」里，两处各出现一次；在「最近」行上打的标签立即反映到标签组。
- 它治的是「未打标 221 条太长」：时间窗口会自己收敛，24 小时内通常只有十几条。

## 标签排序（左栏单列表 + 标签面板）

左栏切到「单列表」时，可以按**槽位**自定义会话的显示顺序：官方置顶、任意标签、最近窗口、未打标，都能被搬到任意位置。「按工作区」「按工作区树」不受影响。

同一套槽位顺序同时决定**标签总览面板的分组顺序**——「最近 N 小时」既是一个可以搬位置的槽位，也会把窗口内有活动的会话在左栏聚成一档。

### 两种模式

| 模式 | 触发 | 行为 |
| :--- | :--- | :--- |
| **默认** | 未设置 `options.tagOrder` | 左栏只让「存档」会话置底，其余按宿主顺序；面板保持 最近 → 待办 → 存档 → 自定义 → 未打标 |
| **自定义** | 在「设置 → 通用设置 → 左栏标签排序」里启用 | 左栏和面板都按槽位顺序；同槽内保持宿主顺序 |

### 槽位模型

```text
最近 24 小时 › 置顶会话 › 待办 › 插件学习 › 学习 › 未打标 › 存档
```

- `最近 N 小时` = 时间窗口（`options.recentHours`，1–720）：窗口内有活动的会话（运行中无条件算）归这一档。把它放在「待办」前面，窗口内的待办会话就先归最近档；放在最后，最近会话就沉底。左栏与标签面板同时生效。
- `置顶会话` = 宿主官方置顶（`pinnedSessionIds`）；把它放在哪，置顶行就显示在哪（能压过宿主置顶）。
- 其余槽位是标签名；`未打标` = 没有任何标签的会话。
- **一个会话有多个候选**（最近 / 置顶 / 多个标签）：把它归到槽位表里最靠前的那个。
- **没有单独排序的标签**（包括以后新建的）：运行时插到「未打标」之前，保持宿主相对顺序，不会丢行。
- **空白草稿**（正在输入的新会话）：永远第一，不参与排序。

### 实现与边界

- 只做**视觉排序**：给单列表容器加插件类（`display:flex`），再给每行的包装写 inline `order`；不写宿主手动排序、不动 DOM 顺序、不改宿主偏好。面板分组顺序只重排 `buildPanelModel` 的组数组。
- 为什么不用 DOM 重排：宿主用 keyed children 渲染，插件移动节点会被下一次 commit 复原；`order` 是纯展示层，切视图 / 刷新 / 标签变化后由 `MutationObserver` 自动重建。
- 开关与编辑入口在「设置 → 通用设置 → 左栏标签排序」；自定义排序存在 `options.tagOrder`，随 `state.json` 跨浏览器。
- 排序弹窗用 `↑` / `↓` 调整，不做拖拽；「恢复默认」清空 `tagOrder`，回到存档置底。
- 旧数据里的 `tagOrder` 没有 `__recent__` 时，面板保持「最近」在最前（升级前后观感不变）；打开编辑器会把它补进列表，用户一动就写入配置。

### 已知代价

- **视觉顺序与 DOM 顺序不一致**：键盘上下移动、拖拽落点仍按宿主的真实顺序走；拖拽后可能「看着放这里、实际存那里」。需要精确拖拽时先恢复默认。
- **置顶可被重排**：自定义排序下宿主置顶行可能不在列表最前，这是显式配置的结果，不拦截。
- **最近窗口太宽会盖住标签**：窗口设成 168 小时且最近槽排在标签前面时，大部分会话都会归最近档，标签槽只剩窗口外的旧会话——这是排序规则的结果，可缩小窗口或把最近槽后移。
- 依赖宿主的 `_flatList` 类名后缀识别单列表；宿主改名时排序会静默失效，但不会破坏布局（分组视图不会被加 flex）。

## 数据模型

```js
// localStorage["session-tag-lite.v1"]
{ version: 1,
  tags: ['待办', '存档', '读书'],        // 全库标签池；保留名永远在最前
  marks: { '<sessionId>': ['待办', '读书'] },
  due:   { '<sessionId>': '2026-11-01' },  // 严格 YYYY-MM-DD，脏值读取时丢弃
  collapsed: { '待办': true, '__untagged__': false },  // true=折叠，false=显式展开
  colors: { '读书': '#7fc4bd' },           // 自定义标签的颜色；缺省回退名字哈希
  options: { recentHours: 24, rowAction: true, panelView: 'tree', archiveLast: true, tagOrder: null } }
                // 「最近」窗口 1–720（脏值回落 24）+ 行尾色盘开关（缺省 true）
                // + 面板视图：'tree'（默认）| 'tabs'，脏值回落 'tree'
                // + 存档置底：缺省 true，只有显式 false 才关闭
                // + 自定义排序：null = 默认；数组 = 槽位顺序
                //   （'__recent__' / '__pinned__' / 标签名 / '__untagged__'；'__recent__' 同时作用于左栏与面板）
```

- 标签名读取时 trim、截断到 24 字符、去重；`marks` 引用到的名字自动回填标签池。
- **旧保留名迁移**：早期版本把保留名写作 `归档`，读入时在标签池、`marks`、`collapsed` 三处统一迁移成 `存档`；用户输入 `归档` 也等同输入 `存档`，避免池里出现两个近义保留名。
- **孤儿标签自动清理**：池里已无任何会话使用、且不是 `待办/存档` 的名字，在下次写入时消失（typeai 也没有"删除标签"界面）。
- 同一份数据也由 Host 落盘（见下节），localStorage 是它的本地镜像。

## 持久化（跨浏览器）

Host 半区注册一条同源路由，读写 `$DSH_HOME/session-tag-lite/state.json`（默认 `~/.dsh/session-tag-lite/state.json`，临时文件 + rename 原子替换）：

| 请求 | 行为 |
| :--- | :--- |
| `GET /plugins/session-tag-lite/state` | `{ ok, revision, data }`；无落盘数据时 `data: null` |
| `PUT /plugins/session-tag-lite/state` | body `{ data }`，持久化后返回 `{ ok, revision }` |

两条请求都必须带 `x-session-tag-lite: 1` 头（跨站表单拼不出来），且只接受同源 `Origin`。

Client 的同步策略是**本地优先**：

1. 启动时先渲染 localStorage（瞬时），再 `GET` 远端。
2. **本地为空、远端有数据**（新浏览器 / 清过站点数据）→ 用远端恢复。
3. **本地有数据** → 保持本地并 `PUT` 覆盖远端。这样另一个客户端的空状态或旧状态不会把本机标签抹掉。
4. 之后每次改动（含新建/删除标签、改色、截止日期）都在 300 ms 防抖后 `PUT` 整份状态。

路由不可用（desktop 构建没有 `webServer`，或 `GET` 非 2xx）→ 整个插件静默退回纯 `localStorage` 单机模式，行为不变。

边界：两个浏览器同时编辑同一会话时是「最后写赢」；跨设备需要自行同步 `~/.dsh` 数据目录。路由只在本机 loopback 上、靠自定义头挡住跨站请求，不做额外的用户认证。

## 颜色

- `待办` = 琥珀 `#d9a441`，`存档` = 灰 `#9a9ca0`，固定不可改。
- 其余 7 色环：雾蓝 / 灰绿 / 藕紫 / 陶红 / 青碧 / 沙棕 / 蓝紫灰。
- **新建标签自动选色**：优先完全没被用过的颜色，其次用得最少的（并列取环内靠前），所以连着建三个标签不会撞色。
- **改色**：编辑器里点标签 pill 上的小色点 → 展开 7 色板 → 选一个；改的是该标签的全局颜色，行尾色盘立即跟着变。
- 旧数据没有 `colors` 字段时按名字哈希取色（升级后观感不变）；标签从池里消失时它的颜色记录一并清理。

## 已知限制

- 「搜索命中标签」实现在插件面板内：宿主左栏搜索框由 `ui-workspace` 内部持有，没有注册点，插件无法让宿主搜索结果包含标签。
- 「最近」窗口读的是会话快照的 `updatedAt`；宿主列表 `updatedAt` 尚未推进时，刚发完消息的会话可能晚一拍才进窗口（运行中会话不受影响）。
- 标签是扁平字符串，没有父子层级；真层级留给后续「路径式标签」方案。
- 「显示全部 N 个」是一次性渲染（实测 223 行 ≈ 6200px 滚动区）；会话数上千前够用，没有做虚拟化。
- 多浏览器同时编辑同一会话时最后写赢（本地优先，不会互相清空）；跨设备需同步 `~/.dsh`。
- 删标签无撤销。
- 标签页视图只记忆「视图」，不记忆当前选中的 tab；每次打开面板默认第一个（通常是「最近」）。
- tab 栏超过一行自动换行，最高 150px，再多就在栏内纵向滚动；不做横向滚动与折叠成“更多”菜单。
- 标签页视图一次渲染当前 tab 的全部行（与树形单组一致），未打标仍保留 15 条预览；会话数上千前没做虚拟化。
- 面板打开时宿主会话行被虚拟列表卸载也不影响：所有读写只按 `sessionId`，不持有 DOM。
- 「左栏标签排序」是视觉排序，键盘遍历 / 拖拽落点仍按宿主真实顺序，详见上文「已知代价」。
- 归档筛选的联动键是 ui-workspace 的持久化契约（`dsh.workspace.view.v5`）：宿主改名或换存储时，联动会静默退回「隐藏已归档」口径（功能降级，不报错）。
- 面板读的是「渲染那一刻」的筛选状态，不订阅宿主 store；面板开着时左栏本来也点不到。

## 宿主契约依赖

- `ctx.slots.inject/register`：`sidebar.workspaces.session.row.action`、`sidebar.workspaces.session.menu.item`、`sidebar.session.row.hover`、`settings.general.item`×2、`shell.overlay`×3、`sidebar.panellist`、`main`（**不注册** `sidebar.session.row.leading`）。
- `ctx.sessions.list`（`SnapshotStore<SessionListState>`）：只读会话快照，读取不激活任何 Session；排序用它判断空白草稿（`byId[id].blank`）。
- `ctx.workspaces.list`（`WorkspaceSource`）：只读 Workspace 快照，取 `archivedSessionIds` 判定归档行、取 `pinnedSessionIds` 判断官方置顶；服务缺失时退回空集。
- `ctx.uiWorkspace.openSession(id)`：从面板打开会话。
- `ctx.uiWorkspace.unarchiveSession(id)`：打开归档行前先取消归档；缺失时只提示。
- `localStorage['dsh.workspace.view.v5']`（**只读**）：宿主左栏 viewing store 里的 `archivedFilter`（`default` / `show` / `only`），面板据此镜像可见集合；读不到时按 `default` 降级。
- `ctx.layout.selectPanel(null)`：`main` 兜底重定向（防止键盘把主面板切到空白键位）。
- Host 半区 `inject: ['webServer']` + `ctx.webServer.register({ kind: 'exact', path: '/plugins/session-tag-lite/state' })`；`webServer` 不存在时插件不激活，Client 自动退回 localStorage。
- 左栏排序只依赖单列表容器的 `_flatList` 类名后缀与行上的 `data-row-key="session:<id>"`（宿主行本来就有的属性）；匹配不上时排序静默不启用。插件自己只在行包装上写 inline `style.order`。
- 颜色只用 `--dsw-alias-*` token + `color-mix`；不改宿主 `data-*`。
